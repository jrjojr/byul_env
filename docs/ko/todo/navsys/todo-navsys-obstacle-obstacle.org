Triangle는 vertex_count=3 convenience adapter로 둔다. Rectangle outline/enclosure/cross/spiral은
typed descriptor를 받고 공통 polygon/line raster core를 사용한다. 모든 실패에서

Descriptor 계약은 다음과 같다.

- =obstacle_enclosure_desc_t=는 half-open =x0/y0/width/height=, 양수 inward
  =wall_thickness_cells=, =open_side=, =aperture_offset_cells=와
  =aperture_length_cells=를 갖는다. CLOSED는 aperture 두 값이 0이어야 하고, 열린 side는
  side 진행축(UP/DOWN은 +X, LEFT/RIGHT는 +Y)에서 offset부터 length만큼 wall-depth 전체를
  제거한다. Aperture가 corner wall과 겹치면 aperture가 우선한다. Interior 한 칸 이상을
  위해 width와 height는 각각 =2*wall_thickness+1= 이상이어야 한다.
- =obstacle_cross_desc_t=는 center, 네 방향 각각의 =arm_length_cells=와 line에 적용할
  Chebyshev =radius_cells=를 갖는다. 두 inclusive axis line의 합집합이며 arm length 0,
  radius 0은 center 한 칸이다.
- =obstacle_spiral_desc_t=는 center, authoritative =max_radius_cells=, 양수
  =pitch_cells=, Chebyshev =path_radius_cells=, direction과 clip rule을 갖는다. Center에서
  시작해 CW는 +X,+Y,-X,-Y, CCW는 +Y,+X,-Y,-X 순서이고 leg length는
  =pitch,pitch,2*pitch,2*pitch,...=다. 다음 path center의 Chebyshev 거리가 max radius를
  넘기 직전에 종료한다. =PATH_ONLY= clip은 centerline만 radius로 제한해 dilation이 밖으로
  나갈 수 있고, =OUTPUT= clip은 최종 cell도 center 기준 max-radius square에 자른다.
  따라서 legacy =turns=는 종료 기준이 아니며 =gap+1=만 pitch 후보로 대응한다.
- 각 descriptor는 =struct_size/abi_version=과 전용 initializer를 갖는다. 필수 pointer와
  descriptor 전체를 options/cancellation보다 먼저 검증한다.

* 함수별 구현 결함과 목표 계약

** Rectangle/random

- filled rectangle은 width/height >0만 검사하고 multiplication/hash insert failure를 무시한다.
- random rectangle은 probability =0=을 invalid/NULL로 처리하고 >1을 조용히 1로 clamp한다.
  Target은 =[0,1]=을 모두 valid로 하며 outside/NaN은 INVALID_ARGUMENT로 거부한다.
- =srand(time)/rand=는 global/thread-unsafe/non-replay다. per-call RNG와 seed provenance로 교체한다.
- 현재 test는 probability 0에서 NULL을 요구하면서 NULL blocked set length도 호출한다. 신규 contract와
  논리 assertion으로 교정한다.

** Beam/line

- extent를 =goal-start=로 만들어 inclusive endpoint와 width/height가 불일치하고 reverse line은
  negative extent가 된다.
- range 0은 start를 제외하고 goal까지 block한다. range >0은 =range-1=로 neighborhood를 구해
  radius 1에서 centerline을 제외하고 주변 이웃만 block하는 등 이름과 다른 hollow 결과가 가능하다.
- Target은 start/end inclusive Bresenham/supercover 선택, radius 0=centerline, radius N의 metric
  (Chebyshev/Manhattan/Euclidean disk)을 typed option으로 고정한다.

** Rect outline/enclosure/cross

- =torus=는 3D torus가 아니라 axis-aligned rectangular ring이다. canonical 명명만 고치고 legacy 유지한다.
- enclosure는 문서의 minimum interior 크기를 검사하지 않는다. open side corner가 다른 side 조건으로
  다시 막힐 수 있어 aperture 범위가 불분명하다.
- thickness/range는 실제로 cell center 주변 square radius여서 선 폭은 =2r+1=이다. thickness가
  one-sided width인지 radius인지 모든 shape에서 통일한다.

** Spiral

- radius는 output metadata extent에만 쓰이고 실제 step 종료에는 사용되지 않는다. =turns*4=와 증가하는
  leg length가 radius 밖 좌표를 block할 수 있다.
- =gap=은 ring spacing이 아니라 step index에 따라 entire leg를 skip한다. direction unknown은 silently CW다.
- Target descriptor는 max radius, pitch/ring spacing, turns 또는 endpoint 중 authoritative parameter,
  raster radius와 clip policy를 분리한다.

** Triangle/polygon

- triangle barycentric dot product가 =int=에서 overflow하고 float division으로 large coordinate precision을 잃는다.
- degenerate triangle은 NULL이 아니라 empty obstacle로 성공한다. boundary inclusion도 불명확하다.
- polygon은 non-const list, self-intersection/duplicate/null vertex/orientation/fill/boundary contract가 없다.
- ray crossing은 even-odd처럼 동작하지만 boundary cell을 안정적으로 포함하지 않는다.
- outline legacy 이름 =*_torus=는 의미가 틀리며 line dilation이 square radius임을 밝히지 않는다.
- Target은 checked 64-bit/wider orientation, validity status, explicit fill/raster rule과 contiguous
  =vertices+count= input을 사용한다. self-intersection support 여부는 capability로 보고한다.

** 확정 계약

*** 좌표, extent와 raster

- 좌표는 정수 cell-center 좌표이며 =+x=는 오른쪽, =+y=는 아래쪽이다. Cell =(x,y)=의
  닫힌 footprint는 =[x-1/2,x+1/2] x [y-1/2,y+1/2]=이다. 거리와 dilation의 기본 metric은
  Chebyshev이고 =radius_cells=0은 원래 centerline/boundary만 뜻한다. 다른 metric을 지원할
  때는 descriptor enum으로 분리하며 암묵적으로 바꾸지 않는다.
- =byul_grid_rect_t{x0,y0,width,height}=는 center 집합
  ={(x,y) | x0 <= x < x0+width, y0 <= y < y0+height}=인 half-open rectangle이다.
  width 또는 height 0은 valid empty이고 성공한 empty obstacle을 반환한다. 끝 좌표 계산은
  wider checked arithmetic로 먼저 검증하며 =coord_t=로 표현할 수 없으면
  =NAVSYS_STATUS_LIMIT_REACHED=다.
- Line은 start와 end를 모두 포함한다. =CELL_CENTER= line은 major-axis step마다 ideal
  line에 가장 가까운 minor-axis center를 선택하는 symmetric Bresenham centerline이다.
  정확히 반-cell인 error tie는 양쪽 center를 모두 포함해 reversal/회전/반사를 보존한다.
  =ALL_TOUCHED= line은 닫힌 cell footprint와 segment가 한 점이라도 만나면 선택하는
  supercover다. Polygon =CELL_CENTER=는 cell center가 fill 내부 또는 boundary에
  있으면 선택하고, =ALL_TOUCHED=는 닫힌 footprint가 fill 또는 boundary와 만나면 선택한다.
  따라서 exact boundary는 Boost.Geometry =covered_by= 비교축처럼 포함한다. 이는 pixel
  center만 기본 선택하고 touched pixel을 별도 선택하는 GDAL 구분을 BYUL 정수 grid에
  옮긴 계약이다.
- Polygon ring은 마지막 vertex를 반복하지 않는 contiguous input이다. 닫는 edge는
  마지막에서 첫 vertex로 암묵적으로 생긴다. =EVEN_ODD=는 crossing parity,
  =NON_ZERO=는 signed winding number를 사용하고 둘 다 boundary를 우선 포함한다.
  Self-intersection은 이 명시적 fill rule로 지원한다. vertex 3개 미만, 연속 중복
  (마지막/첫 vertex 포함), 모든 edge가 한 직선 위인 ring은 =INVALID_ARGUMENT=다.
  Vertex 순서 반전은 두 fill rule의 cell 집합을 바꾸지 않는다.
- Shape의 logical extent 밖 좌표를 조용히 생성한 뒤 metadata만 자르지 않는다. Rect와
  descriptor에 명시된 clip extent는 half-open center extent에서 raster 단계에 clip하고,
  polygon/line처럼 별도 extent가 없는 shape는 선택된 cell의 최소 half-open bounding rect를
  결과 extent로 삼는다. Empty result의 canonical extent는 descriptor origin의 0x0 rect다.

*** status, limit와 cancellation

| condition | status/result |
|-----------+---------------|
| required NULL, invalid enum/descriptor, NaN 또는 =[0,1]= 밖 probability | =INVALID_ARGUMENT=, =*out_obstacle=NULL= |
| 유효하지만 선택 cell 0개 | =OK=, destroy 가능한 non-NULL empty obstacle |
| 지원하지 않는 metric/shape capability | =UNSUPPORTED=; 다른 rule로 fallback하지 않음 |
| coordinate/count 산술이 public type 또는 =size_t=로 표현 불가 | =LIMIT_REACHED= |
| unique selected cell이 양수 =max_cells= 초과 | =LIMIT_REACHED= |
| allocation 실패 | =OUT_OF_MEMORY= |
| callback이 true / C++ 예외 발생 | =CANCELLED= / =CALLBACK_FAILED= |

- =options=NULL=은 =CELL_CENTER=, seed 0, =max_cells=0=, cancellation 없음이다.
  =max_cells=0=은 user budget을 두지 않는다는 뜻일 뿐 checked representability와 allocation
  한계를 없애지 않는다. 양수 값은 unique output cell의 hard ceiling이며 초과 cell을
  commit하기 전에 실패한다.
- Required pointer, enum, probability와 descriptor validation을 cancellation보다 먼저 한다.
  그 뒤 최초 allocation 전, raster candidate 1024개마다, dedup/materialize의 각 1024개
  chunk 전에 callback을 poll한다. Callback/userdata는 call 동안만 borrow하며 보관하지 않는다.
- 모든 non-OK 종료는 failure-atomic이다. Partial obstacle을 반환하지 않고
  =*out_obstacle=NULL=을 유지한다. 같은 input에서 limit/cancel polling 순서도 deterministic이다.

*** random rectangle replay

- RNG는 per-call =SplitMix64-v1=이다. 64-bit state를 exact seed로 초기화하고 각 half-open
  rectangle cell을 =y= 증가, 같은 row에서 =x= 증가 순서로 한 번씩 draw한다. Global RNG와
  시간 seed를 읽지 않는다.
- Draw =r=에 대해 =u=r/2^64=인 exact rational로 정의하고 blocked iff =u < p=다. 구현은
  IEEE-754 binary64 =p.as_integer_ratio()=와 동등한 integer cross multiplication을 사용해
  floating multiplication/rounding 차이를 피한다. 따라서 =p=0은 empty, =p=1은 전부이며
  같은 seed/descriptor/options는 platform과 thread에 무관하게 같은 set을 만든다.

*** legacy mapping과 incompatibility

| legacy | target mapping | implementation decision |
|--------+----------------+-------------------------|
| rect all blocked | half-open filled rect | positive extent는 lossless라 canonical forwarding; legacy non-positive NULL guard 유지 |
| rect random | random rect + explicit seed | global time/rand, p=0 NULL, >1 clamp와 replay 불가 때문에 legacy 구현 보존 |
| beam | inclusive line + Chebyshev radius | reverse extent, range 0 endpoint 누락과 range 1 hollow 동작 때문에 legacy 구현 보존 |
| torus | rect outline + one-sided inward wall width | positive valid extent는 lossless라 canonical forwarding; 이름만 deprecated |
| enclosure | rect outline + side/aperture span descriptor | corner 재차단과 minimum interior 미검증 때문에 legacy 구현 보존 |
| cross | two inclusive orthogonal lines + Chebyshev radius | nonnegative safe input은 lossless라 descriptor forwarding |
| spiral | max radius/pitch/turns/direction descriptor | legacy gap의 entire-leg skip과 metadata-only radius 때문에 legacy 구현 보존 |
| triangle | 3-vertex polygon fill | legacy float/barycentric boundary, degenerate empty와 overflow 동작 때문에 legacy 구현 보존 |
| triangle torus | 3-vertex polygon outline + Chebyshev radius | tie에서 한 경로만 고르는 legacy Bresenham과 symmetric canonical raster가 달라 legacy 구현 보존 |
| polygon | contiguous vertices + even-odd center fill | mutable list, float boundary와 invalid ring 동작 때문에 legacy 구현 보존 |
| polygon torus | polygon outline + Chebyshev radius | legacy Bresenham tie와 invalid ring 동작 때문에 legacy 구현 보존 |
