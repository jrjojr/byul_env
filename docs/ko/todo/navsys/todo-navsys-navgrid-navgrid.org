* 업계 비교와 목표 모델

- [[https://docs.godotengine.org/en/stable/classes/class_astargrid2d.html][Godot AStarGrid2D]]는 region, solid, weight, diagonal mode를 분리하고 네 가지 corner
  정책을 명시한다. 단순 4/8 enum만으로 traversal topology가 완성되지 않는다.
- [[https://recastnav.com/classdtNavMeshQuery][Detour query API]]는 caller buffer/capacity/count와 status/partial을 쓴다. neighbor마다
  heap list를 반환하는 API 대신 two-call/caller-buffer가 canonical이어야 한다.
- [[https://www.glfw.org/docs/latest/window.html][GLFW user pointer/callback]]은 userdata 초기값과 object lifetime을 명시한다. callback과
  userdata는 하나의 bind operation으로 교체해야 한다.
- [[https://www.sqlite.org/c3ref/sqlite3.html][SQLite opaque handle]]처럼 owning map/callback layout을 SDK에서 숨긴다.

* Navcell 3단계에서 확정한 ABI 1.x terrain mutation 경계

- legacy =navgrid_block_coord=은 absent cell에만 =FORBIDDEN/0=을 저장한다. 기존
  non-forbidden cell은 덮어쓰지 않고 false를 반환하여 terrain/height를 보존한다.
- legacy =navgrid_unblock_coord=은 =FORBIDDEN= cell만 제거하여 sparse default로 복원한다.
  absent 또는 non-forbidden cell은 변경하지 않고 false를 반환한다.
- 이 경계는 provenance 없는 ABI 1.x 함수의 비손실 fallback이다. prior cell 복원과
  multi-source overlay는 이 문서의 checked cell mutation·overlay 4단계에서 구현한다.

** 결정과 증거

- =navgrid-semantic-policy.json=에 canonical extent, topology, query, cell과 resize 계약을
  고정했다. Bounded grid는 int32 origin과 양의 uint32 extent의 half-open
  =[origin, origin + extent)=를 사용하며 endpoint는 signed 64-bit로 검증한다. Unbounded는
  origin/extent =0/0/0/0=인 별도 flag 상태다. 신규 create/resize는 negative dimension,
  bounded zero extent, overflow와 noncanonical unbounded descriptor를 거부한다.
- Legacy ABI 1.x의 =0= axis별 unbounded, negative =[dimension,0)=와 setter의 field-only
  resize는 그대로 characterization했다. 이 형태는 canonical semantic으로 승격하지 않으며,
  mixed-unbounded와 negative extent는 legacy-only다.
- Canonical 4방향 순서는 각도 기준 =E/S/W/N=, 8방향은
  =E/SE/S/SW/W/NW/N/NE=다. 0도는 =+x=, positive angle은 =atan2(+y,+x)=이고
  tie는 normalized angle이 작은 후보를 선택한다. 4방향 degree/goal은 8방향 table의 앞
  4개를 재사용하지 않는다. Legacy owned-list 순서 =N/W/E/S= 및 기존 8방향 확장 순서는
  ABI 1.x에서 유지한다.
- Diagonal policy는 =NEVER/ALWAYS/IF_ONE_ORTHOGONAL_OPEN/
  IF_BOTH_ORTHOGONALS_OPEN= 네 종류로 확정했다. Destination과 두 orthogonal은 동일한
  effective blocked query로 평가하고 한 callback이라도 실패하면 전체 query가
  =CALLBACK_FAILED=로 실패하며 output을 보존한다.
- Coordinate query 결과는 inside absent, inside present passable/blocked, bounded outside,
  callback failure와 corrupt stored cell을 각각 presence/blocked와
  =OK/NOT_FOUND/CALLBACK_FAILED/CORRUPT_STATE=로 구분한다. Absent는 sparse entry가 없는

  extent, cell, overlay와 output 전체를 보존한다. Callback binding과 topology는 유지한다.
- 정책 test는 nonzero origin의 작은 extent 전체 좌표, 4개 diagonal policy와 두 orthogonal의
  모든 open/blocked 조합, deterministic order/tie, resize clip property를 19/19로 검증했다.
  Native fixture는 legacy negative/mixed-unbounded bounds, outside cell 보존 resize,
  4/8 exact order와 현행 4-dir degree 결함을 characterization했다.

  CFFI와 current ABI inventory =--check=도 통과했다. 이 단계는 public declaration/export와
  ABI layout을 변경하지 않았다.
